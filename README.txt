스윙 랩 v1.2 - 설치 요약

1) 깃허브(github.com) 가입, 2단계 인증 켜기, 이메일 비공개 설정
2) 모델 파일 2개를 SOURCES.txt의 구글 주소에서 받아 이 폴더에 넣기
3) 깃허브에 새 저장소(Public) 만들고, 이 폴더 안의 파일을 전부 올리기
4) 저장소 Settings > Pages 에서 main 브랜치로 켜기 → 주소 생김
5) 아이폰 사파리로 주소 열기 → 공유 → 홈 화면에 추가 (웹 앱으로 열기 켜기)

업데이트할 때: 바뀐 파일을 같은 저장소에 다시 올리면(덮어쓰기) 끝.
폰에서는 앱을 껐다 켜면 새 버전이 적용돼요.
문제가 생기면: 설정 > 진행 기록 보기 화면을 캡처해서 클로드에게 보내 주세요.

위성지도(선택): 브이월드(vworld.kr)에서 인증키를 받아 앱 설정 > 위성지도에 붙여넣기.
키 발급할 때 서비스 주소는 https://kth2315-lang.github.io 로 등록.
